# Emotion_recognition_system
# Система рекомендацій контенту на основі емоційного аналізу

## Опис проекту

Інноваційна система рекомендацій, яка використовує технології комп'ютерного зору для аналізу емоційних реакцій користувача під час перегляду контенту та надання персоналізованих рекомендацій на основі цих даних.

## Архітектура системи

Система складається з трьох основних компонентів:

### 1. Клієнтська частина (Frontend)
- **Технології**: MediaPipe Landmarks
- **Функціональність**: 
  - Захоплення відео з веб-камери користувача
  - Виявлення та відстеження лендмарків обличчя в реальному часі
  - Передача даних про лендмарки на сервер для аналізу
  - Відображення контенту та рекомендацій

### 2. Сервер аналізу (Analysis Server)
- **Функціональність**:
  - Отримання даних про лендмарки обличчя від клієнта
  - Аналіз емоційного стану користувача за допомогою натренованої ML моделі
  - Категоризація контенту на основі результатів емоційного аналізу
  - Передача результатів до рекомендаційного сервісу

### 3. Рекомендаційний сервіс (Recommendation Service)
- **Функціональність**:
  - Управління базою даних контенту та користувачів
  - Генерація персоналізованих рекомендацій
  - Зберігання історії взаємодії користувачів
  - API для взаємодії з іншими компонентами системи

## Технологічний стек

### Frontend
- MediaPipe (для розпізнавання лендмарків)
- JavaScript/TypeScript
- HTML5/CSS3
- WebRTC (для доступу до камери)

### Backend
- Python (для ML аналізу)
- TensorFlow/PyTorch (ML модель)
- REST API
- База даних (PostgreSQL/MongoDB)

### DevOps
- Docker
- GitHub Actions (CI/CD)

## Принцип роботи

1. **Захоплення даних**: Клієнтська частина використовує MediaPipe для виявлення 468 лендмарків обличчя користувача
2. **Передача на сервер**: Координати лендмарків передаються на сервер аналізу через захищене з'єднання
3. **Емоційний аналіз**: Натренована модель аналізує дані та визначає емоційний стан користувача
4. **Категоризація**: Контент категоризується відповідно до виявленої емоції
5. **Рекомендації**: Рекомендаційний сервіс генерує персоналізовані пропозиції на основі емоційного профілю

## API Документація

### Endpoints сервера аналізу
- `POST /analyze-landmarks` - Аналіз лендмарків обличчя
- `GET /emotions/{user_id}` - Отримання історії емоцій користувача

### Endpoints рекомендаційного сервісу
- `GET /recommendations/{user_id}` - Отримання рекомендацій
- `POST /content` - Додавання нового контенту
- `GET /users/{user_id}/profile` - Профіль користувача

## Особливості системи

### Переваги
- **Персоналізація**: Рекомендації адаптуються до емоційного стану користувача
- **Приватність**: Обробка відео здійснюється локально, передаються лише координати лендмарків
- **Масштабованість**: Мікросервісна архітектура дозволяє легко масштабувати компоненти
- **Точність**: Використання 468 лендмарків забезпечує високу точність розпізнавання емоцій

### Технічні рішення
- Оптимізація передачі даних через стиснення координат лендмарків
- Кешування результатів аналізу для покращення продуктивності
- Асинхронна обробка запитів для кращої відповідності

## Безпека та приватність

- Шифрування даних при передачі (HTTPS/WSS)
- Анонімізація персональних даних
- Згода користувача на використання камери
- Відповідність GDPR вимогам
